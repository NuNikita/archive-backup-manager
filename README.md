# Архив

Учебное веб-приложение для резервного копирования и восстановления файлов. Веб-интерфейс и обработчик заданий написаны на Go. PostgreSQL хранит настройки и историю операций, а restic создаёт зашифрованные копии.

## Возможности

- Ручное копирование и запуск по расписанию.
- Хранение нескольких версий и восстановление выбранной версии в отдельную папку.
- Проверка целостности копий и просмотр истории операций.
- Две роли: администратор управляет заданиями, наблюдатель просматривает их состояние.

## Запуск

Понадобится Docker с Compose. При первом запуске создайте в корне проекта файл `.env` и задайте четыре разных пароля. Используйте латинские буквы и цифры, не менее 20 символов для каждого пароля.

```dotenv
POSTGRES_PASSWORD=
ADMIN_PASSWORD=
VIEWER_PASSWORD=
RESTIC_PASSWORD=
```

Из корня проекта выполните:

```sh
docker compose up --build -d
```

Откройте [веб-интерфейс](http://localhost:8080). Для входа используйте `admin` или `viewer` с соответствующим паролем из `.env`.

## Демонстрация

Войдите как `admin` и запустите копирование в задании «Документы компании». Оно использует примеры из `demo-data/documents`. После завершения операции выберите созданный снимок и нажмите «Восстановить версию». Путь к восстановленным файлам появится в журнале операции.
